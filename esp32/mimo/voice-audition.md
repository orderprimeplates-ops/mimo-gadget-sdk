# MIMO voice audition

Compare providers with the **same words, in the same order**, at each
provider's default speed. Use free demos only; no API keys or billing needed.

## Where to listen

| Provider | Official demo | Notes |
|---|---|---|
| ElevenLabs | [Text to speech](https://elevenlabs.io/text-to-speech), [Voice Library](https://elevenlabs.io/app/voice-library) | Free account for the library. Its library refuses child-like voices, so look for youthful, bright, playful voices |
| Cartesia | [Playground](https://play.cartesia.ai), [voice generator](https://www.cartesia.ai/voice-generator) | Free account; the public web demo takes about 500 characters (use the short script) |
| Azure | [Voice Gallery](https://speech.microsoft.com/portal/voicegallery) | Try without signing up. Some voices offer the `Boy` role and styles such as `cheerful` |

## Short script (307 characters; fits every demo)

> Hi! I'm MIMO. I'm so happy to see you! Hmm... let me think. Your Prime
> Plates order for table twelve is ready. Oh! And don't forget: the 3:30
> meeting starts in fifteen minutes. You've got this. Want to hear a joke?
> Okay... why did the marshmallow cross the road? To get toasted! Hee hee.
> Good night, friend.

## Full script (about 45 seconds)

> **Greeting:** Hi! I'm MIMO. I'm so happy to see you!
>
> **Thinking:** Hmm... let me think about that for a second.
>
> **Helpful:** Your Prime Plates order for table twelve is ready, and three
> new orders came in since noon.
>
> **Reminder:** Oh! Don't forget: the 3:30 meeting starts in fifteen minutes.
>
> **Gentle:** That sounds like a hard day. I'm right here with you.
>
> **Playful:** Want to hear a joke? Why did the marshmallow cross the road?
> To get toasted! Hee hee!
>
> **Numbers:** That's $1,284.50 across 37 orders, up 12 percent.
>
> **Goodbye:** Good night, friend. Sweet dreams!

## Score each voice (1–5)

| | ElevenLabs | Cartesia | Azure |
|---|---|---|---|
| Sweet and warm | | | |
| Youthful and boyish, not childish or creepy | | | |
| Expressive (joke, empathy, excitement) | | | |
| Clear on a small speaker (play it from your phone's speaker) | | | |
| Numbers, times and "Prime Plates" said right | | | |
| Natural pauses ("Hmm...", "Oh!") | | | |
| **Total** | | | |

Write down the exact voice name you liked from each, and the style or role
(Azure), so the relay can use it. For the small speaker, play the demo from
a phone at low volume: that's closest to MIMO's 1.75C speaker.
